# Mod 叙事交接模板

本文件用于把 [Remix-AI 故事蓝本](story-bible.md) 转为另一个 Mod 工程可讨论的设计提案。AI 军工方向已确认；具体科技协议、单位、数值与平衡尚未确定。本文件不表示任何功能已经实现。

每份提案记录：蓝本版本、来源仓库、采用的 Git commit、提案状态。当前蓝本版本为 **0.1**；Git commit 在实际导入时填写，避免以工作区状态代替版本基线。角色引用使用稳定 ID `hammer`、`bastion`、`ghost`。

## 空白模板

基线：版本 ______ / 仓库 ______ / commit ______
状态：设计提案，待确认

| 字段 | 内容 |
| --- | --- |
| 阵营 | 苏联 / 盟军 / 升阳；涉及人物时附稳定 ID |
| 叙事依据 | 引用蓝本中已确认的设定；新增假设单独标明 |
| AI 功能 | 希望表现的辅助判断、协同或其他功能；权限边界待确认 |
| 科技依赖 | 与本阵营已确认科技路线的联系，以及新增的技术假设 |
| 协议或单位 | 拟采用的玩法载体；未决定时填写“待定” |
| 反制与平衡 | 可讨论的弱点、成本、范围与反制；无已确认数值时不填定值 |
| 待确认 | 列出剧情、权限、实现方式、单位归属及平衡上的未决问题 |

## 三方示例（均为设计提案）

以下示例只展示如何从既定科技方向提出问题，均不是已确定协议、单位或已实现内容。

| 字段 | 苏联示例：设计提案 | 盟军示例：设计提案 | 升阳示例：设计提案 |
| --- | --- | --- | --- |
| 阵营 | 苏联；涉及指挥官时使用 `hammer` | 盟军；涉及指挥官时使用 `bastion` | 升阳；涉及指挥官时使用 `ghost` |
| 叙事依据 | 火箭与太空资源支持算力集群 | 冰冻科技支持海底算力集群 | 纳米芯片制程提升算力 |
| AI 功能 | 可提议以集群计算辅助战场态势判断 | 可提议以算力支持防线与支援调度建议 | 可提议以高算力芯片辅助局部机动判断 |
| 科技依赖 | 如何把太空资源与战场计算连接起来，方案待定 | 海底算力如何服务前线，冷却和连接方案待定 | 芯片的部署载体、供能与计算范围待定 |
| 协议或单位 | 待定；可讨论协议、设施或单位承载，尚未选型 | 待定；可讨论协议、设施或单位承载，尚未选型 | 待定；可讨论协议、设施或单位承载，尚未选型 |
| 反制与平衡 | 可讨论供能或连接依赖是否构成弱点，不预设中断效果 | 可讨论海底设施依赖与维护成本，不预设冷却惩罚 | 可讨论供能、散热和成本取舍，不预设具体增益 |
| 待确认 | 联网权限、宿主知情程度、载体、成本与反制机制 | 联网关系、服务范围、载体、成本与反制机制 | 芯片权限、计算范围、载体、成本与反制机制 |

任何由示例引出的新科技能力或限制，均须作为提案另行确认。讨论通过后先更新相应叙事或设计记录，再由 Mod 工程决定实现方式和验证方案。
